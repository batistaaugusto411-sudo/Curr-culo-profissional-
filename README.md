# Portfólio & Currículo Web

Este é um projeto desenvolvido em HTML5 semântico como parte de um desafio prático do SENAI. A página funciona como um portfólio/currículo web para o desenvolvedor Augusto Batista, apresentando informações de apresentação pessoal, lista de habilidades, tabela de projetos concluídos e formulário de contato estruturado.

---

## Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação da página utilizando boas práticas e tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<table>`, `<fieldset>`, `<footer>`).
* **Navegação Âncora:** Links internos para rolagem direta entre as seções da página (`#sobremim`, `#projetos`, `#contato`).
* **Formulários e Tabelas:** Uso de campos de entrada com rótulos (`<label>`), menus suspensos (`<select>`), áreas de texto e agrupamento com `<fieldset>`.

---

## Estrutura da Página

A página foi organizada nas seguintes seções:

* **Cabeçalho & Navegação:** Título principal e menu com atalhos diretos para as seções da página.
* **Seção Sobre Mim:** 
  * Foto de perfil dimensionada em 150x150px.
  * Breve resumo sobre formação e estudos no SENAI.
  * Lista de principais habilidades técnicas.
* **Seção Meus Projetos:** Tabela estruturada com 4 colunas (*Projeto*, *Tecnologias*, *Status* e *Link*) destacando trabalhos desenvolvidos.
* **Seção Entre em Contato:** Formulário completo envolto em um `<fieldset>` ("Dados do Contato"), contendo campos para Nome, E-mail, Assunto (menu suspenso), Mensagem e botão de envio.
* **Rodapé:** Informações do processo (`&copy;`), links diretos para e-mail e telefone.
